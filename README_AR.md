# إعادة تنظيم باك إند a7la_makan — المرحلة الأولى

هذه نسخة أولية من تقسيم الكود، وليست منشورة على Cloudflare.

## الملفات
- `worker.js`: نقطة الدخول، وبقية وظائف الموقع ومسارات API كما كانت.
- `src/config.js`: الثوابت ودوال مستويات الصلاحيات.
- `src/http.js`: إنشاء استجابات JSON وقراءة جسم الطلب ومعالجة أخطاء الخادم.
- `src/security.js`: التشفير وكلمات المرور والجلسات والتحقق من المستخدم ومحاولات الدخول.
- `schema.sql`: نسخة مرجعية من ملف المخطط الأصلي دون تعديل.

## ما الذي لم يتغير؟
- لم يتم تغيير مسارات API أو منطق وظائفها.
- لم يتم تعديل `schema.sql` أو حذف/إعادة إنشاء أي جدول.
- لم يتم تعديل ملفات `public` أو الواجهة الأمامية.
- لم يتم تعديل إعدادات `wrangler.jsonc`. استخدم ملفك الأصلي كما هو.

## قبل النشر
1. احتفظ بنسخة احتياطية من المشروع الحالي.
2. انسخ `src/` و`worker.js` إلى نسخة اختبار من مشروعك.
3. اترك `wrangler.jsonc` الأصلي كما هو.
4. نفّذ `npx wrangler deploy` فقط بعد نجاح الاختبار المحلي ومراجعة الفرق.

هذه المرحلة تنقل الأدوات الأساسية فقط. بقية الوظائف ما زالت داخل `worker.js` عمدًا لتقليل المخاطر، وسيكون نقلها لاحقًا وحدةً وحدة.
